2. `_place_nfp(order, rotations_choice, material, sheet_h)`:
   ```
   placed = []                                   # (artwork_id, position, rotation, contour_ja_girado)
   para cada peça na 'order' (com a rotação escolhida, via Polygon.rotated):
       peca_off = _offset(peça, gap/2)
       regiao = _ifp_rect(peca_off, chapa)        # onde pode ficar dentro da chapa
       para cada p já em placed:
           nfp = _nfp(p.contour_off, peca_off)    # NFP relativo
           nfp_pos = nfp transladado para a POSIÇÃO REAL de p   # <-- CRÍTICO (ver Regra de Ouro nº2)
           regiao = regiao DIFERENÇA nfp_pos      # pyclipper CT_DIFFERENCE
       se regiao vazia: peça não coube nesta chapa (deixa de fora, registra)
       candidatos = TODOS os vértices dos polígonos de 'regiao'
       ref = candidato que MINIMIZA (y, x)        # bottom-left: empacota denso p/ baixo, depois p/ esquerda
       fixa peça com bbox.min em 'ref'; adiciona a placed
   return placed
   ```
