## GEOMETRIA COM FUROS (base compartilhada — fazer primeiro)
Criar em `app/domain/geometry/` um tipo `PolygonWithHoles`:
```python
@dataclass(frozen=True, slots=True)
class PolygonWithHoles:
    outer: Polygon                       # contorno externo (anel único)
    holes: tuple[Polygon, ...] = ()      # furos (vazio = sem furo)
```
- Orientação canônica: `outer` anti-horário, `holes` horário (use Polygon.signed_area/is_clockwise para normalizar).
- `bounding_box` = do outer. `area_liquida` = area(outer) − soma(area dos holes).
Estender `NestingShape` (em true_shape.py) para carregar furos SEM quebrar nada:
```python
holes: tuple[Polygon, ...] = ()          # default vazio → 2A–2E continuam idênticos
```
IMPORTANTE: o motor de nesting usa SÓ o `contour` externo (furos não afetam o empacotamento; inside_check é
fase futura). Os furos são apenas CARREGADOS para a Fase 4 exportar (a máquina precisa cortar o buraco também).
Na Fase 4, o MESMO transform (girar em torno do bbox.min do outer + transladar para position) se aplica ao
outer E a todos os holes juntos — senão o furo desalinha do corpo da letra.
